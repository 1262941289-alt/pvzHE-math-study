# 第6讲 导数与微分 📚

## 📖 本讲概述

导数是微积分学的核心概念之一，它描述了函数的变化率。本讲将学习导数的定义、几何意义、求导法则，以及微分的概念和应用。

## 🎯 学习目标

- 理解导数的定义和几何意义
- 掌握基本函数的导数公式
- 熟练运用求导法则
- 理解微分的概念和计算方法
- 掌握高阶导数的求法

## 📋 知识点结构

### 1. 导数的定义

#### 1.1 导数的定义

函数f(x)在点x₀处的导数定义为：
f'(x₀) = lim(h→0) [f(x₀+h) - f(x₀)]/h

等价形式：
f'(x₀) = lim(x→x₀) [f(x) - f(x₀)]/(x - x₀)

#### 1.2 左导数和右导数

- **左导数**：f'₋(x₀) = lim(h→0⁻) [f(x₀+h) - f(x₀)]/h
- **右导数**：f'₊(x₀) = lim(h→0⁺) [f(x₀+h) - f(x₀)]/h

导数存在的充要条件：f'₋(x₀) = f'₊(x₀)

#### 1.3 导数的几何意义

f'(x₀)表示曲线y = f(x)在点(x₀, f(x₀))处切线的斜率。

切线方程：y - f(x₀) = f'(x₀)(x - x₀)

### 2. 基本函数的导数公式

#### 2.1 常数和幂函数

- (c)' = 0
- (xⁿ)' = nxⁿ⁻¹
- (x^α)' = αx^(α-1)

#### 2.2 指数和对数函数

- (aˣ)' = aˣ ln a
- (eˣ)' = eˣ
- (log_a x)' = 1/(x ln a)
- (ln x)' = 1/x

#### 2.3 三角函数

- (sin x)' = cos x
- (cos x)' = -sin x
- (tan x)' = sec²x
- (cot x)' = -csc²x
- (sec x)' = sec x tan x
- (csc x)' = -csc x cot x

#### 2.4 反三角函数

- (arcsin x)' = 1/√(1-x²)
- (arccos x)' = -1/√(1-x²)
- (arctan x)' = 1/(1+x²)
- (arccot x)' = -1/(1+x²)

### 3. 求导法则

#### 3.1 四则运算法则

设u = u(x)，v = v(x)都可导，则：
- (u ± v)' = u' ± v'
- (uv)' = u'v + uv'
- (u/v)' = (u'v - uv')/v² (v ≠ 0)

#### 3.2 复合函数求导法则（链式法则）

设y = f(u)，u = g(x)，则：
dy/dx = (dy/du) · (du/dx)

即：[f(g(x))]' = f'(g(x)) · g'(x)

#### 3.3 反函数求导法则

设y = f(x)的反函数为x = φ(y)，则：
φ'(y) = 1/f'(x) (f'(x) ≠ 0)

#### 3.4 隐函数求导

对方程F(x,y) = 0两边同时对x求导，利用链式法则求出dy/dx。

#### 3.5 参数方程求导

设参数方程为：x = φ(t)，y = ψ(t)，则：
dy/dx = (dy/dt)/(dx/dt) = ψ'(t)/φ'(t)

### 4. 微分的概念

#### 4.1 微分的定义

如果函数y = f(x)在点x处的增量可以表示为：
Δy = A·Δx + o(Δx)
其中A是不依赖于Δx的常数，则称f(x)在点x处可微，并称A·Δx为f(x)在点x处的微分，记作dy或df(x)。

#### 4.2 微分与导数的关系

dy = f'(x)dx

#### 4.3 微分的几何意义

微分dy表示切线上点的纵坐标的增量。

#### 4.4 微分的运算法则

- d(u ± v) = du ± dv
- d(uv) = vdu + udv
- d(u/v) = (vdu - udv)/v²
- d[f(u)] = f'(u)du

### 5. 高阶导数

#### 5.1 高阶导数的定义

- 二阶导数：f''(x) = [f'(x)]'
- n阶导数：f^(n)(x) = [f^(n-1)(x)]'

#### 5.2 常见函数的高阶导数

- (eˣ)^(n) = eˣ
- (sin x)^(n) = sin(x + nπ/2)
- (cos x)^(n) = cos(x + nπ/2)
- (xᵐ)^(n) = m(m-1)...(m-n+1)x^(m-n)

#### 5.3 莱布尼茨公式

(uv)^(n) = Σ(k=0 to n) C(n,k) u^(k) v^(n-k)

### 6. 导数的应用

#### 6.1 求切线和法线方程

- 切线方程：y - y₀ = f'(x₀)(x - x₀)
- 法线方程：y - y₀ = -1/f'(x₀)(x - x₀)

#### 6.2 相关变化率

利用链式法则求解实际问题中的变化率。
