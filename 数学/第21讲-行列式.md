# 第21讲 行列式 📚

## 📖 本讲概述

行列式是线性代数的基础概念，它不仅是一个数值计算工具，更是理解线性变换、求解线性方程组的重要工具。本讲将系统学习行列式的定义、性质和计算方法。

## 🎯 学习目标

- 理解行列式的定义和几何意义
- 掌握行列式的基本性质
- 熟练计算各种类型的行列式
- 掌握行列式的展开方法
- 理解行列式与线性方程组的关系

## 📋 知识点结构

### 1. 行列式的定义

#### 1.1 二阶行列式

|a₁₁  a₁₂|
|a₂₁  a₂₂| = a₁₁a₂₂ - a₁₂a₂₁

#### 1.2 三阶行列式

|a₁₁  a₁₂  a₁₃|
|a₂₁  a₂₂  a₂₃| = a₁₁|a₂₂  a₂₃| - a₁₂|a₂₁  a₂₃| + a₁₃|a₂₁  a₂₂|
|a₃₁  a₃₂  a₃₃|      |a₃₂  a₃₃|      |a₃₁  a₃₃|      |a₃₁  a₃₂|

#### 1.3 n阶行列式的完全展开式

det(A) = Σ(-1)^τ(j₁j₂...jₙ) a₁j₁a₂j₂...aₙjₙ

其中τ(j₁j₂...jₙ)是排列j₁j₂...jₙ的逆序数。

### 2. 行列式的性质

#### 2.1 基本性质

1. **转置性质**：|A^T| = |A|
2. **互换性质**：互换两行（列），行列式变号
3. **倍乘性质**：某行（列）乘以k，行列式乘以k
4. **相加性质**：某行（列）加上另一行（列）的k倍，行列式不变

#### 2.2 重要性质

- 如果行列式有两行（列）相同，则行列式为0
- 如果行列式有一行（列）全为0，则行列式为0
- 如果行列式有两行（列）成比例，则行列式为0

#### 2.3 乘积性质

|AB| = |A||B|

### 3. 行列式的计算方法

#### 3.1 定义法

直接按定义计算，适用于低阶行列式。

#### 3.2 展开法（代数余子式展开）

按第i行展开：|A| = Σ(j=1 to n) aᵢⱼAᵢⱼ
按第j列展开：|A| = Σ(i=1 to n) aᵢⱼAᵢⱼ

其中Aᵢⱼ = (-1)^(i+j)Mᵢⱼ为代数余子式，Mᵢⱼ为余子式。

#### 3.3 化三角形法

利用行列式性质，通过行变换将行列式化为上三角形或下三角形，然后计算对角线元素的乘积。

#### 3.4 递推法

对于某些特殊结构的行列式，可以建立递推关系。

### 4. 特殊行列式

#### 4.1 上（下）三角行列式

上三角行列式等于主对角线元素的乘积：
|a₁₁  a₁₂  ...  a₁ₙ|
|0    a₂₂  ...  a₂ₙ| = a₁₁a₂₂...aₙₙ
|...  ...  ...  ...|
|0    0    ...  aₙₙ|

#### 4.2 对角行列式

对角行列式等于对角线元素的乘积。

#### 4.3 反对角行列式

|0    0    ...  a₁ₙ|
|0    0    ...  a₂,ₙ₋₁| = (-1)^(n(n-1)/2) a₁ₙa₂,ₙ₋₁...aₙ₁
|...  ...  ...  ...|
|aₙ₁  0    ...  0  |

#### 4.4 范德蒙德行列式

|1    1    ...  1   |
|x₁   x₂   ...  xₙ  | = ∏(1≤i<j≤n) (xⱼ - xᵢ)
|x₁²  x₂²  ...  xₙ² |
|...  ...  ...  ... |
|x₁ⁿ⁻¹ x₂ⁿ⁻¹ ... xₙⁿ⁻¹|

### 5. 行列式的应用

#### 5.1 克拉默法则

对于n元线性方程组Ax = b，当|A| ≠ 0时，方程组有唯一解：
xᵢ = |Aᵢ|/|A|

其中Aᵢ是将A的第i列替换为b得到的矩阵。

#### 5.2 矩阵可逆的判定

方阵A可逆的充要条件是|A| ≠ 0。

#### 5.3 向量组线性相关性的判定

n个n维向量线性相关的充要条件是以这些向量为列的行列式为0。

### 6. 行列式的几何意义

#### 6.1 二阶行列式的几何意义

二阶行列式的绝对值表示由两个向量构成的平行四边形的面积。

#### 6.2 三阶行列式的几何意义

三阶行列式的绝对值表示由三个向量构成的平行六面体的体积。

#### 6.3 n阶行列式的几何意义

n阶行列式的绝对值表示n维空间中由n个向量构成的n维平行多面体的"体积"。
