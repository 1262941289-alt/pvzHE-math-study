# 第2讲 数列极限 📚

## 📖 本讲概述

数列极限是极限理论的起点，也是微积分学的基础概念之一。通过本讲学习，你将理解极限的本质含义，掌握数列极限的定义、性质和计算方法。

## 🎯 学习目标

- 理解数列极限的ε-N定义
- 掌握数列极限的性质
- 熟练运用极限的四则运算法则
- 掌握重要极限的计算方法
- 学会用夹逼定理求极限

## 📋 知识点结构

### 1. 数列极限的定义

#### 1.1 直观理解

- 数列{aₙ}当n→∞时，aₙ无限接近某个常数A
- 记作：lim(n→∞) aₙ = A

#### 1.2 ε-N定义（精确定义）

对于数列{aₙ}，如果存在常数A，使得对于任意给定的正数ε，总存在正整数N，当n > N时，恒有|aₙ - A| < ε，则称数列{aₙ}收敛于A。

#### 1.3 几何意义

- 在数轴上，当n足够大时，aₙ都落在(A-ε, A+ε)内
- ε可以任意小，N相应地要足够大

### 2. 数列极限的性质

#### 2.1 唯一性

如果lim(n→∞) aₙ = A，则极限A是唯一的。

#### 2.2 有界性

如果lim(n→∞) aₙ = A，则数列{aₙ}有界。

#### 2.3 保号性

如果lim(n→∞) aₙ = A > 0，则存在N，当n > N时，aₙ > 0。

### 3. 数列极限的运算法则

#### 3.1 四则运算法则

设lim(n→∞) aₙ = A，lim(n→∞) bₙ = B，则：

- **加法**：lim(n→∞) (aₙ + bₙ) = A + B
- **减法**：lim(n→∞) (aₙ - bₙ) = A - B  
- **乘法**：lim(n→∞) (aₙ · bₙ) = A · B
- **除法**：lim(n→∞) (aₙ / bₙ) = A / B (B ≠ 0)

#### 3.2 复合运算

如果lim(n→∞) aₙ = A，f(x)在A处连续，则：
lim(n→∞) f(aₙ) = f(A)

### 4. 重要的数列极限

#### 4.1 基本极限

- lim(n→∞) 1/n = 0
- lim(n→∞) 1/nᵏ = 0 (k > 0)
- lim(n→∞) aⁿ = 0 (|a| < 1)
- lim(n→∞) ⁿ√n = 1
- lim(n→∞) ⁿ√a = 1 (a > 0)

#### 4.2 重要极限公式

- lim(n→∞) (1 + 1/n)ⁿ = e
- lim(n→∞) (1 + k/n)ⁿ = eᵏ

### 5. 数列极限的计算方法

#### 5.1 直接计算法

- 利用基本极限和运算法则
- 适用于简单的有理函数型数列

#### 5.2 夹逼定理（夹逼准则）

如果aₙ ≤ bₙ ≤ cₙ，且lim(n→∞) aₙ = lim(n→∞) cₙ = A，
则lim(n→∞) bₙ = A。

#### 5.3 单调有界定理

单调有界数列必有极限。
- 单调递增有上界 ⟹ 极限存在
- 单调递减有下界 ⟹ 极限存在

#### 5.4 Stolz定理

设{aₙ}单调递增趋于+∞，如果lim(n→∞) (bₙ₊₁ - bₙ)/(aₙ₊₁ - aₙ) = l，
则lim(n→∞) bₙ/aₙ = l。

### 6. 常见题型及解法

#### 6.1 有理函数型

分子分母同时除以n的最高次幂

#### 6.2 根式型

分子分母有理化或配方

#### 6.3 指数型

利用重要极限lim(n→∞) (1 + 1/n)ⁿ = e

#### 6.4 阶乘型

利用Stirling公式或比值判别法
