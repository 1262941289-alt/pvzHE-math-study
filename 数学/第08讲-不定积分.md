## 📋 知识点结构

### 1️⃣ 原函数与不定积分的概念

---

#### 1.1 原函数的定义

> **定义 1.1** 设函数 f(x) 定义在某区间 I 上，若存在可导函数 F(x)，对于该区间上任意一点都有 F'(x) = f(x) 成立，则称 F(x) 是 f(x) 在区间 I 上的[一个原函数](#12-原函数存在定理)。

> **定义 1.2** 称 ∫f(x)dx = F(x) + C 为 f(x) 在区间 I 上的**不定积分**。

---

#### 📝 关键概念解析

**🔹 原函数（Antiderivative）**

- **定义**：如果函数 F(x) 在区间 I 上可导，且 F'(x) = f(x)，则 F(x) 称为 f(x) 的原函数

- **特点**：原函数不唯一，若 F(x) 是 f(x) 的一个原函数，则 F(x) + C（C 为任意常数）都是 f(x) 的原函数

- **几何意义**：原函数的图像是被积函数 f(x) 的切线斜率函数

**🔹 不定积分（Indefinite Integral）**

- **定义**：函数 f(x) 的所有原函数的集合，记作 ∫f(x)dx = F(x) + C

- **符号说明**：
  - ∫ 称为积分号
  - f(x) 称为被积函数
  - dx 称为积分变量
  - C 称为积分常数

- **本质**：不定积分表示的是一个函数族，而不是单一函数

**🔹 积分常数 C**

- **含义**：由于导数运算会消除常数项，所以积分时必须加上任意常数 C

- **重要性**：C 的存在体现了原函数的不唯一性

- **确定方法**：通常需要初始条件或边界条件来确定 C 的具体值

#### 💡 重要理解要点

| 要点 | 说明 |
|------|------|
| 🔸 原函数的获得 | 原函数是通过求导得到被积函数的 |
| 🔸 原函数的唯一性 | 原函数不唯一，相差一个常数 C |
| 🔸 不定积分的本质 | 不定积分表示所有原函数的集合 |

---

#### 1.2 原函数存在定理

> **定理 1.1** 如果函数 f(x) 在区间 I 上连续，则 f(x) 在 I 上必存在原函数。

**🤔 思考问题：为什么强调"一个"原函数？**

**💭 解答：**

- 因为若 F'(x) = f(x)，则对于任何常数 C，都有 (F(x) + C)' = F'(x) = f(x)
- 故 F(x) + C 也是 f(x) 的原函数
- 所以 f(x) 若有原函数，则原函数有无穷多个
- F(x) + C (C为任意常数) 称为全体原函数

---

#### 1.3 不定积分的完整定义

> **定义 1.3** 函数 f(x) 的所有原函数的全体称为 f(x) 的不定积分，记作：
>
> **∫f(x)dx = F(x) + C**

#### 📋 符号说明

| 符号 | 名称 | 说明 |
|------|------|------|
| ∫ | 积分号 | 表示积分运算 |
| f(x) | 被积函数 | 需要求原函数的函数 |
| f(x)dx | 被积表达式 | 完整的积分表达式 |
| x | 积分变量 | 积分所针对的变量 |
| C | 积分常数 | 任意常数，体现原函数的不唯一性 |

#### 1.4 典型例题解析

---

##### 📝 例题 1

**题目：** 设 0 < x < 1，且 ∫(1-x²)f'(x²)dx = arcsin x + C，则 f(x) = (    )。

**选项：**

- (A) (1-x)^(1/2)
- (B) (1-x)^(-1/2)
- (C) (1-x²)^(1/2)
- (D) (1-x²)^(-1/2)

---

**🔍 解题思路：**
根据原函数 F(x) 的定义及 F'(x) = f(x) 求解。

**📋 解题步骤：**

**步骤1：** 将所给等式两边对 x 求导

∫[(1-x²)f'(x²)]' dx = (arcsin x + C)'

**步骤2：** 化简得到

(1-x²)f'(x²) = 1/√(1-x²)

**步骤3：** 求解 f'(x²)

f'(x²) = (1-x²)^(-1) · 1/√(1-x²) = (1-x²)^(-3/2)

**步骤4：** 得到最终答案

f(x) = (1-x)^(-1/2)

---

**✅ 答案：(B)**

---

##### 📝 例题 2

**题目：** 函数 f(x) = {√(1+x²), x ≤ 0; (x+1)cos x, x > 0}，求一个原函数。

---

#### 📚 相关理论基础

**🔹 定义1：分段函数的原函数**

设函数 f(x) 在区间 I 上有定义，如果存在函数 F(x)，使得在 I 上处处有 F'(x) = f(x)，则称 F(x) 为 f(x) 在区间 I 上的一个原函数。

对于分段函数 f(x) = {f₁(x), x∈I₁; f₂(x), x∈I₂; ...}，其原函数 F(x) 必须满足：

1. 在各个子区间内，F'(x) = f(x)
2. F(x) 在整个定义域上连续

**🔹 定义2：原函数存在定理**

如果函数 f(x) 在区间 [a,b] 上连续，则 f(x) 在 [a,b] 上必有原函数。

**🔹 定义3：分界点连续性条件**

设 f(x) 在 x = x₀ 处有跳跃间断，但在 x₀ 的左右邻域内连续，则 f(x) 的原函数 F(x) 在 x = x₀ 处必须连续，即：

lim[x→x₀⁻] F(x) = lim[x→x₀⁺] F(x) = F(x₀)

---

**🔍 解题分析：**

这是一个分段函数求原函数的问题。根据原函数（不定积分）存在定理，需要分别对每段进行积分，并保证在分界点处的连续性。

---

**📋 解题步骤：**

**🔸 步骤1：分别求各段的原函数**

**对于 x ≤ 0：**

```
∫√(1+x²)dx = (1/2)x√(1+x²) + (1/2)ln|x + √(1+x²)| + C₁
```

> 💡 这是标准的根式积分公式，可通过三角代换或查表得到

**对于 x > 0：**

```
∫(x+1)cos x dx = ∫x cos x dx + ∫cos x dx
                = x sin x - ∫sin x dx + sin x + C₂
                = x sin x + cos x + sin x + C₂
                = (x+1)sin x + cos x + C₂
```

> 💡 使用分部积分法：∫x cos x dx = x sin x + cos x

---

**🔸 步骤2：检验分界点的连续性**

设原函数为 F(x)，则：

| 区间 | 原函数表达式 |
|------|-------------|
| x ≤ 0 | F(x) = (1/2)x√(1+x²) + (1/2)ln\|x + √(1+x²)\| + C₁ |
| x > 0 | F(x) = (x+1)sin x + cos x + C₂ |

为了使 F(x) 在 x = 0 处连续，需要：

```
lim[x→0⁻] F(x) = lim[x→0⁺] F(x)
```

---

**🔸 步骤3：计算极限值**

**左极限：**

```
lim[x→0⁻] F(x) = 0 + (1/2)ln(1) + C₁ = C₁
```

**右极限：**

```
lim[x→0⁺] F(x) = 1·sin(0) + cos(0) + C₂ = 0 + 1 + C₂ = 1 + C₂
```

---

**🔸 步骤4：确定常数关系**

由连续性条件：

```
C₁ = 1 + C₂，即 C₁ - C₂ = 1
```

**第五步：写出最终答案**

取C₂ = 0，则C₁ = 1，得到一个原函数：

F(x) = {
  (1/2)x√(1+x²) + (1/2)ln|x + √(1+x²)| + 1,  x ≤ 0
  (x+1)sin x + cos x,                          x > 0
}

**验证：**

- F'(x) = f(x)在各段内成立 ✓
- F(x)在x = 0处连续 ✓

**重要注意事项：**

1. **分段函数求原函数的关键步骤：**
   - 分别对各段进行积分
   - 检查在分界点处的连续性
   - 通过连续性条件确定常数关系

2. **连续性检验的重要性：**
   - 原函数必须在整个定义域上连续
   - 即使被积函数在某点不连续，其原函数也必须连续
   - 这是原函数存在定理的要求

3. **常数的处理：**
   - 每段积分都会产生一个任意常数
   - 通过边界条件（连续性）来确定常数间的关系
   - 最终得到的是一个具体的原函数，而不是原函数族

4. **符号说明：**
   - ∫f(x)dx 表示f(x)的全体原函数（原函数族）
   - F(x) 表示一个具体的原函数

### 2. 不定积分的基本性质

#### 2.1 线性性质

- ∫[f(x) ± g(x)]dx = ∫f(x)dx ± ∫g(x)dx
- ∫kf(x)dx = k∫f(x)dx (k为常数)

#### 2.2 微分与积分的关系

- d/dx[∫f(x)dx] = f(x)
- ∫F'(x)dx = F(x) + C

### 3. 基本积分公式

#### 3.1 幂函数积分

- ∫x^n dx = x^(n+1)/(n+1) + C (n ≠ -1)
- ∫1/x dx = ln|x| + C

#### 3.2 指数函数积分

- ∫e^x dx = e^x + C
- ∫a^x dx = a^x/ln a + C (a > 0, a ≠ 1)

#### 3.3 三角函数积分

- ∫sin x dx = -cos x + C
- ∫cos x dx = sin x + C
- ∫sec²x dx = tan x + C
- ∫csc²x dx = -cot x + C
- ∫sec x tan x dx = sec x + C
- ∫csc x cot x dx = -csc x + C

#### 3.4 反三角函数积分

- ∫1/√(1-x²) dx = arcsin x + C
- ∫1/(1+x²) dx = arctan x + C

### 4. 第一类换元法（凑微分法）

#### 4.1 基本思想

如果∫f(u)du = F(u) + C，则∫f(φ(x))φ'(x)dx = F(φ(x)) + C

#### 4.2 常用的凑微分公式

- ∫f(ax+b)dx = 1/a ∫f(ax+b)d(ax+b)
- ∫f(x²)·x dx = 1/2 ∫f(x²)d(x²)
- ∫f(ln x)/x dx = ∫f(ln x)d(ln x)
- ∫f(e^x)e^x dx = ∫f(e^x)d(e^x)

#### 4.3 解题步骤

1. 观察被积函数的结构
2. 寻找合适的中间变量u = φ(x)
3. 凑出du = φ'(x)dx
4. 化为基本积分形式
5. 计算积分并回代

### 5. 第二类换元法（变量替换法）

#### 5.1 基本思想

设x = φ(t)，dx = φ'(t)dt，则：
∫f(x)dx = ∫f(φ(t))φ'(t)dt

#### 5.2 常用替换

- **三角替换**：
  - √(a²-x²) → x = a sin t
  - √(a²+x²) → x = a tan t  
  - √(x²-a²) → x = a sec t

- **根式替换**：
  - √(ax+b) → t = √(ax+b)
  - ⁿ√(ax+b) → t = ⁿ√(ax+b)

- **倒数替换**：
  - 分母次数高于分子 → x = 1/t

### 6. 分部积分法

#### 6.1 分部积分公式

∫u dv = uv - ∫v du

或写成：∫u(x)v'(x)dx = u(x)v(x) - ∫v(x)u'(x)dx

#### 6.2 选择u和dv的原则

按照"反对幂指三"的顺序选择u：

- **反**：反三角函数
- **对**：对数函数
- **幂**：幂函数
- **指**：指数函数
- **三**：三角函数

#### 6.3 常见类型

- ∫x^n e^x dx
- ∫x^n sin x dx, ∫x^n cos x dx
- ∫x^n ln x dx
- ∫e^x sin x dx, ∫e^x cos x dx

### 7. 有理函数的积分

#### 7.1 有理函数的定义

形如P(x)/Q(x)的函数，其中P(x)、Q(x)都是多项式。

#### 7.2 部分分式分解

将有理函数分解为简单分式的和：

- **不同的一次因式**：A/(x-a)
- **重复的一次因式**：A₁/(x-a) + A₂/(x-a)² + ... + Aₖ/(x-a)ᵏ
- **不可约二次因式**：(Ax+B)/(x²+px+q)

#### 7.3 积分计算

- ∫A/(x-a) dx = A ln|x-a| + C
- ∫A/(x-a)ⁿ dx = -A/((n-1)(x-a)ⁿ⁻¹) + C (n > 1)

### 8. 常见积分类型总结

#### 8.1 根据被积函数特点选择方法

- **多项式**：直接积分
- **有理函数**：部分分式分解
- **三角函数**：三角恒等变换或换元
- **指数函数**：换元或分部积分
- **根式函数**：三角替换或根式替换

#### 8.2 积分技巧

- **观察法**：寻找被积函数与某个函数导数的关系
- **凑微分**：将复杂积分化为基本积分
- **巧用恒等式**：利用三角恒等式等简化被积函数
