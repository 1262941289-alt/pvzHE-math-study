# 第26讲 随机事件与概率 📚

## 📖 本讲概述

随机事件与概率是概率论的基础，它研究随机现象的规律性。本讲将学习随机事件的概念、概率的定义、概率的基本性质和计算方法。

## 🎯 学习目标

- 理解随机试验、样本空间、随机事件的概念
- 掌握概率的定义和基本性质
- 熟练运用概率的加法公式和乘法公式
- 掌握条件概率和独立性的概念
- 学会用全概率公式和贝叶斯公式解题

## 📋 知识点结构

### 1. 随机试验与样本空间

#### 1.1 随机试验

随机试验是指满足以下条件的试验：

1. 可以在相同条件下重复进行
2. 每次试验的可能结果不止一个，且能事先明确所有可能结果
3. 进行一次试验之前不能确定哪一个结果会出现

#### 1.2 样本空间

随机试验E的所有可能结果组成的集合称为样本空间，记作Ω。
样本空间中的每个元素称为样本点，记作ω。

#### 1.3 随机事件

样本空间Ω的子集称为随机事件，简称事件，通常用大写字母A、B、C等表示。

**特殊事件**：

- **必然事件**：Ω（每次试验必然发生）
- **不可能事件**：∅（每次试验都不发生）
- **基本事件**：只包含一个样本点的事件

### 2. 事件的关系与运算

#### 2.1 事件的关系

- **包含关系**：A ⊂ B，事件A发生必然导致事件B发生
- **相等关系**：A = B，A ⊂ B且B ⊂ A
- **互斥关系**：A ∩ B = ∅，事件A和B不能同时发生
- **对立关系**：A ∩ B = ∅且A ∪ B = Ω

#### 2.2 事件的运算

- **并事件**：A ∪ B，事件A或事件B发生
- **交事件**：A ∩ B，事件A和事件B同时发生
- **差事件**：A - B，事件A发生但事件B不发生
- **对立事件**：Ā，事件A不发生

#### 2.3 运算律

- **交换律**：A ∪ B = B ∪ A，A ∩ B = B ∩ A
- **结合律**：(A ∪ B) ∪ C = A ∪ (B ∪ C)
- **分配律**：A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
- **德摩根律**：(A ∪ B)ᶜ = Aᶜ ∩ Bᶜ

### 3. 概率的定义

#### 3.1 概率的统计定义（频率定义）

在n次重复试验中，事件A发生了nₐ次，则频率fₙ(A) = nₐ/n。
当n → ∞时，fₙ(A)稳定在某个常数附近，这个常数称为事件A的概率。

#### 3.2 概率的古典定义

设试验的样本空间Ω包含有限个等可能的基本事件，事件A包含k个基本事件，则：
P(A) = k/n = A包含的基本事件数/基本事件总数

#### 3.3 概率的公理化定义

设Ω为样本空间，对于每个事件A，都有一个实数P(A)与之对应，称为事件A的概率，且满足：

1. **非负性**：P(A) ≥ 0
2. **规范性**：P(Ω) = 1
3. **可列可加性**：对于两两互斥的事件A₁, A₂, ...，有P(∪Aᵢ) = ΣP(Aᵢ)

### 4. 概率的基本性质

#### 4.1 基本性质

- P(∅) = 0
- P(Ā) = 1 - P(A)
- 若A ⊂ B，则P(A) ≤ P(B)
- 0 ≤ P(A) ≤ 1

#### 4.2 加法公式

- **两个事件**：P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
- **三个事件**：P(A ∪ B ∪ C) = P(A) + P(B) + P(C) - P(A ∩ B) - P(A ∩ C) - P(B ∩ C) + P(A ∩ B ∩ C)

### 5. 条件概率

#### 5.1 条件概率的定义

设A、B为两个事件，且P(B) > 0，则称P(A|B) = P(A ∩ B)/P(B)为在事件B发生的条件下事件A发生的条件概率。

#### 5.2 条件概率的性质

- P(Ω|B) = 1
- 若A₁, A₂, ...两两互斥，则P(∪Aᵢ|B) = ΣP(Aᵢ|B)

#### 5.3 乘法公式

- **两个事件**：P(A ∩ B) = P(B)P(A|B) = P(A)P(B|A)
- **多个事件**：P(A₁A₂...Aₙ) = P(A₁)P(A₂|A₁)P(A₃|A₁A₂)...P(Aₙ|A₁A₂...Aₙ₋₁)

### 6. 事件的独立性

#### 6.1 两个事件的独立性

事件A和B相互独立，当且仅当P(A ∩ B) = P(A)P(B)。

等价条件：

- P(A|B) = P(A)（当P(B) > 0时）
- P(B|A) = P(B)（当P(A) > 0时）

#### 6.2 多个事件的独立性

事件A₁, A₂, ..., Aₙ相互独立，当且仅当对于任意的k(2 ≤ k ≤ n)和任意的1 ≤ i₁ < i₂ < ... < iₖ ≤ n，都有：
P(Aᵢ₁Aᵢ₂...Aᵢₖ) = P(Aᵢ₁)P(Aᵢ₂)...P(Aᵢₖ)

### 7. 全概率公式与贝叶斯公式

#### 7.1 全概率公式

设B₁, B₂, ..., Bₙ是样本空间Ω的一个划分，且P(Bᵢ) > 0，则对任一事件A有：
P(A) = Σᵢ₌₁ⁿ P(Bᵢ)P(A|Bᵢ)

#### 7.2 贝叶斯公式

在全概率公式的条件下，若P(A) > 0，则：
P(Bⱼ|A) = P(Bⱼ)P(A|Bⱼ) / Σᵢ₌₁ⁿ P(Bᵢ)P(A|Bᵢ)

### 8. 常见概率模型

#### 8.1 古典概型

- 基本事件有限且等可能
- 计算方法：P(A) = |A|/|Ω|

#### 8.2 几何概型

- 样本空间为几何区域
- 计算方法：P(A) = A的测度/Ω的测度
