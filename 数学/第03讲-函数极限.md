# 第3讲 函数极限 📚

## 📖 本讲概述

函数极限是微积分学的核心概念，比数列极限更加复杂和重要。本讲将学习函数极限的定义、性质、计算方法，以及重要的极限定理。

## 🎯 学习目标

- 理解函数极限的ε-δ定义
- 掌握函数极限的性质和运算法则
- 熟练计算各种类型的函数极限
- 掌握重要极限公式的应用
- 学会用洛必达法则求极限

## 📋 知识点结构

### 1. 函数极限的定义

#### 1.1 自变量趋于有限值时的极限

设函数f(x)在点x₀的某个去心邻域内有定义，如果存在常数A，使得对于任意给定的正数ε，总存在正数δ，当0 < |x - x₀| < δ时，恒有|f(x) - A| < ε，则称f(x)当x→x₀时的极限为A。

记作：lim(x→x₀) f(x) = A

#### 1.2 左极限和右极限

- **左极限**：lim(x→x₀⁻) f(x) = A₁
- **右极限**：lim(x→x₀⁺) f(x) = A₂
- **极限存在的充要条件**：A₁ = A₂ = A

#### 1.3 自变量趋于无穷时的极限

- lim(x→∞) f(x) = A
- lim(x→+∞) f(x) = A  
- lim(x→-∞) f(x) = A

### 2. 函数极限的性质

#### 2.1 唯一性

如果lim(x→x₀) f(x)存在，则极限值唯一。

#### 2.2 局部有界性

如果lim(x→x₀) f(x) = A，则f(x)在x₀的某个去心邻域内有界。

#### 2.3 局部保号性

如果lim(x→x₀) f(x) = A > 0，则存在δ > 0，当0 < |x - x₀| < δ时，f(x) > 0。

### 3. 函数极限的运算法则

#### 3.1 四则运算法则

设lim(x→x₀) f(x) = A，lim(x→x₀) g(x) = B，则：

- lim(x→x₀) [f(x) ± g(x)] = A ± B
- lim(x→x₀) [f(x) · g(x)] = A · B
- lim(x→x₀) [f(x) / g(x)] = A / B (B ≠ 0)

#### 3.2 复合函数的极限

如果lim(x→x₀) g(x) = u₀，lim(u→u₀) f(u) = A，且在x₀的某个去心邻域内g(x) ≠ u₀，则：
lim(x→x₀) f(g(x)) = A

### 4. 重要极限公式

#### 4.1 第一个重要极限

lim(x→0) (sin x)/x = 1

**推广形式**：

- lim(x→0) (tan x)/x = 1
- lim(x→0) (arcsin x)/x = 1
- lim(x→0) (arctan x)/x = 1

#### 4.2 第二个重要极限

lim(x→∞) (1 + 1/x)ˣ = e

**推广形式**：

- lim(x→0) (1 + x)^(1/x) = e
- lim(x→∞) (1 + k/x)ˣ = eᵏ

### 5. 函数极限的计算方法

#### 5.1 直接代入法

当f(x)在x₀处连续时，lim(x→x₀) f(x) = f(x₀)

#### 5.2 因式分解法

适用于0/0型未定式

#### 5.3 有理化法

适用于含根式的极限

#### 5.4 等价无穷小替换

当x→0时：

- sin x ~ x
- tan x ~ x  
- arcsin x ~ x
- arctan x ~ x
- ln(1+x) ~ x
- eˣ - 1 ~ x
- (1+x)ᵅ - 1 ~ αx

#### 5.5 洛必达法则

对于0/0或∞/∞型未定式，如果lim f'(x)/g'(x)存在，则：
lim f(x)/g(x) = lim f'(x)/g'(x)

### 6. 无穷小与无穷大

#### 6.1 无穷小的定义

如果lim(x→x₀) f(x) = 0，则称f(x)是当x→x₀时的无穷小。

#### 6.2 无穷小的性质

- 有限个无穷小的和仍是无穷小
- 有界函数与无穷小的乘积是无穷小
- 无穷小与无穷小的乘积是无穷小

#### 6.3 无穷小的比较

设α、β都是x→x₀时的无穷小：

- 如果lim α/β = 0，称α是β的高阶无穷小
- 如果lim α/β = c ≠ 0，称α与β是同阶无穷小
- 如果lim α/β = 1，称α与β是等价无穷小
