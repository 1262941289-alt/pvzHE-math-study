# MCP寸止工具配置说明

## 📋 **配置文件说明**

### 1. **mcp-config.json**
- **用途**：MCP服务器的主配置文件
- **包含**：寸止、记忆、context7-mcp三个服务器的配置
- **位置**：项目根目录

### 2. **vscode-mcp-settings.json**
- **用途**：VSCode IDE的MCP集成配置
- **包含**：IDE中MCP客户端的设置
- **使用方法**：将内容添加到VSCode的settings.json中

### 3. **寸止.py**
- **用途**：寸止工具的Python实现
- **功能**：提供寸止询问和寸止确认两个核心功能
- **协议**：遵循MCP 2024-11-05协议标准

### 4. **寸止.bat**
- **用途**：Windows下启动寸止工具的批处理脚本
- **功能**：检查Python环境并启动寸止MCP服务器

## 🔧 **配置步骤**

### 步骤1：环境准备
1. 确保安装了Python 3.7+
2. 确保IDE支持MCP协议（如VSCode with MCP extension）

### 步骤2：文件配置
1. 将所有配置文件放在项目根目录
2. 根据实际情况修改配置文件中的路径

### 步骤3：IDE集成
1. 在IDE中配置MCP服务器连接
2. 将vscode-mcp-settings.json的内容添加到IDE设置中

### 步骤4：测试连接
1. 运行`寸止.bat`启动服务器
2. 在IDE中测试MCP工具是否可用

## ⚠️ **注意事项**

1. **Python依赖**：确保Python环境正确配置
2. **路径设置**：根据实际情况调整配置文件中的路径
3. **权限问题**：确保脚本有执行权限
4. **编码问题**：所有文件使用UTF-8编码

## 🔍 **故障排除**

### 问题1：Python未找到
- **解决**：安装Python 3.7+并添加到PATH环境变量

### 问题2：MCP连接失败
- **解决**：检查配置文件路径和IDE MCP扩展是否正确安装

### 问题3：工具无响应
- **解决**：检查寸止.py脚本是否正常运行，查看错误日志
