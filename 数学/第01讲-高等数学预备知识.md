# 第1讲 高等数学预备知识 📚

## 📖 本讲概述

高等数学预备知识是整个考研数学的基础，就像建房子的地基一样重要。本讲主要复习高中数学中的重要概念和方法，为后续学习做好准备。

## 🎯 学习目标

- 掌握函数的基本概念和四种特性
- 熟练掌握基本初等函数的图像和性质
- 掌握图像变换的基本方法
- 了解极坐标和参数方程
- 熟记常用的基础知识和公式

## 📋 知识点结构

### 1. 函数概念与特性

#### 1.1 函数的定义

- **定义域**：函数有意义的x的取值范围
- **值域**：函数值y的取值范围  
- **对应法则**：x到y的变换规律

#### 1.2 函数的四种特性

##### 单调性

- **单调递增**：x₁ < x₂ ⟹ f(x₁) ≤ f(x₂)
- **单调递减**：x₁ < x₂ ⟹ f(x₁) ≥ f(x₂)

##### 奇偶性

- **偶函数**：f(-x) = f(x)，图像关于y轴对称
- **奇函数**：f(-x) = -f(x)，图像关于原点对称

##### 周期性

- **周期函数**：f(x+T) = f(x)，T为周期

##### 有界性

- **有界**：存在M > 0，使得|f(x)| ≤ M

### 2. 基本初等函数图像

#### 2.1 幂函数

- y = x^n (n为正整数)
- y = x^(1/n) (n为正整数)
- y = x^(-n) (n为正整数)

#### 2.2 指数函数

- y = aˣ (a > 0, a ≠ 1)
- 特别地：y = eˣ

#### 2.3 对数函数

- y = log_a x (a > 0, a ≠ 1)
- 特别地：y = ln x

#### 2.4 三角函数

- y = sin x, y = cos x, y = tan x
- y = cot x, y = sec x, y = csc x

#### 2.5 反三角函数

- y = arcsin x, y = arccos x, y = arctan x

### 3. 图像变换

#### 3.1 平移变换

- **水平平移**：y = f(x ± a)
- **竖直平移**：y = f(x) ± b

#### 3.2 伸缩变换

- **水平伸缩**：y = f(ax)
- **竖直伸缩**：y = af(x)

#### 3.3 对称变换

- **关于x轴对称**：y = -f(x)
- **关于y轴对称**：y = f(-x)
- **关于原点对称**：y = -f(-x)

### 4. 极坐标与参数方程

#### 4.1 极坐标

- **极坐标与直角坐标的关系**：
  - x = r cos θ
  - y = r sin θ
  - r² = x² + y²
  - tan θ = y/x

#### 4.2 参数方程

- **参数方程的一般形式**：
  - x = φ(t)
  - y = ψ(t)

### 5. 常用基础知识

#### 5.1 重要不等式

- **均值不等式**：√(ab) ≤ (a+b)/2
- **柯西不等式**：(a₁b₁ + a₂b₂)² ≤ (a₁² + a₂²)(b₁² + b₂²)

#### 5.2 重要极限

- lim(x→0) (sin x)/x = 1
- lim(x→∞) (1 + 1/x)ˣ = e

#### 5.3 常用公式

- **二项式定理**：(a + b)ⁿ = Σ C(n,k) aⁿ⁻ᵏ bᵏ
- **三角恒等式**：sin²x + cos²x = 1

## 💡 重点难点

### 重点

1. 函数的四种特性的判断和应用
2. 基本初等函数的图像和性质
3. 图像变换的规律

### 难点

1. 复合函数的性质判断

## 🔄 学习方法

1. **概念理解**：深入理解函数概念的本质
2. **图像记忆**：通过图像理解函数性质
3. **变换规律**：掌握图像变换的一般规律
4. **多做练习**：通过练习巩固基础知识
