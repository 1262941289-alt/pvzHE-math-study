# 第4讲 函数的连续性 📚

## 📖 本讲概述

函数的连续性是极限理论的重要应用，也是微积分学的基础概念。本讲将学习连续性的定义、性质、连续函数的运算，以及间断点的分类。

## 🎯 学习目标

- 理解函数连续性的定义
- 掌握连续函数的性质和运算法则
- 学会判断函数的连续性
- 掌握间断点的分类方法
- 理解闭区间上连续函数的性质

## 📋 知识点结构

### 1. 函数连续性的定义

#### 1.1 在一点处的连续性

函数f(x)在点x₀处连续的充要条件：
lim(x→x₀) f(x) = f(x₀)

等价于三个条件同时满足：

1. f(x₀)有定义
2. lim(x→x₀) f(x)存在
3. lim(x→x₀) f(x) = f(x₀)

#### 1.2 左连续和右连续

- **左连续**：lim(x→x₀⁻) f(x) = f(x₀)
- **右连续**：lim(x→x₀⁺) f(x) = f(x₀)

#### 1.3 在区间上的连续性

- **开区间连续**：在区间内每一点都连续
- **闭区间连续**：在开区间连续，且在端点处单侧连续

### 2. 连续函数的性质

#### 2.1 连续函数的四则运算

设f(x)、g(x)在点x₀处连续，则：

- f(x) ± g(x)在x₀处连续
- f(x) · g(x)在x₀处连续
- f(x) / g(x)在x₀处连续（g(x₀) ≠ 0）

#### 2.2 复合函数的连续性

设u = g(x)在x₀处连续，y = f(u)在u₀ = g(x₀)处连续，则复合函数y = f(g(x))在x₀处连续。

#### 2.3 反函数的连续性

设y = f(x)在区间I上严格单调且连续，则其反函数x = f⁻¹(y)在对应区间上也连续。

### 3. 基本初等函数的连续性

#### 3.1 连续的基本初等函数

- 常数函数：y = c
- 幂函数：y = xⁿ
- 指数函数：y = aˣ
- 对数函数：y = log_a x
- 三角函数：y = sin x, y = cos x等
- 反三角函数：y = arcsin x等

#### 3.2 初等函数的连续性

初等函数在其定义域内都是连续的。

### 4. 函数的间断点

#### 4.1 间断点的定义

如果函数f(x)在点x₀处不连续，则称x₀为f(x)的间断点。

#### 4.2 间断点的分类

##### 第一类间断点（可去间断点和跳跃间断点）

左极限和右极限都存在：

- **可去间断点**：lim(x→x₀⁻) f(x) = lim(x→x₀⁺) f(x) ≠ f(x₀)
- **跳跃间断点**：lim(x→x₀⁻) f(x) ≠ lim(x→x₀⁺) f(x)

##### 第二类间断点（无穷间断点和振荡间断点）

左极限或右极限至少有一个不存在：

- **无穷间断点**：极限为无穷大
- **振荡间断点**：函数在该点附近振荡

### 5. 闭区间上连续函数的性质

#### 5.1 有界性定理

在闭区间[a,b]上连续的函数f(x)必定有界。

#### 5.2 最值定理

在闭区间[a,b]上连续的函数f(x)必定能取到最大值和最小值。

#### 5.3 介值定理

设f(x)在[a,b]上连续，且f(a) ≠ f(b)，则对于f(a)和f(b)之间的任意数η，必存在ξ ∈ (a,b)，使得f(ξ) = η。

#### 5.4 零点定理

设f(x)在[a,b]上连续，且f(a)·f(b) < 0，则存在ξ ∈ (a,b)，使得f(ξ) = 0。

### 6. 一致连续性

#### 6.1 一致连续的定义

函数f(x)在区间I上一致连续，是指对于任意ε > 0，存在δ > 0，使得对于I上任意两点x₁、x₂，只要|x₁ - x₂| < δ，就有|f(x₁) - f(x₂)| < ε。

#### 6.2 Cantor定理

在闭区间[a,b]上连续的函数必定一致连续。
